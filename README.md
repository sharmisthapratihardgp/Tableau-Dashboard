Project Overview: 
This Tableau project presents a comprehensive Sales Performance Dashboard that analyzes revenue, customer behavior, product performance, and geographic distribution.
The dashboard is built using multiple analytical views to provide both high-level KPIs and detailed drill-down insights.
The project includes the following worksheets:
KPI Card Sheet – Summary metrics (Total Sales, Revenue, etc.)
KPI Metric – Key performance indicators overview
Monthly Trend – Sales trend over time
Sales by Weekday – Revenue distribution by day of week
Cancelled vs Completed Sales – Order status comparison
Customer Frequency – Customer purchase behavior analysis
Top 10 Customers by Revenue
Top 10 Products by Sale
Top N Countries
Country Map – Geographic sales distribution
Sales Histogram – Sales distribution analysis
Sales Treemap – Product/category contribution
Heatmap – Pattern and intensity visualization
Scatter Plot – Relationship analysis between key variables
Data Quality Sheet – Data validation and quality checks
